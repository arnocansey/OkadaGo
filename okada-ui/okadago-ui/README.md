# okadago-ui (design reference only)

These screens under `okadago-admin/` are **not** the live admin console.

- Live admin: `frontend/admin-app` (separate Vercel project / `admin.okadago.com`)
- Design reference mockups only in this folder — not the live console
- Mockup gallery (dev): `/ui` when `ENABLE_UI_SHOWCASE=true` or non-production

Do not wire product routes to files in this folder.
